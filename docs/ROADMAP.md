# Roadmap

This file is the plan of the site of the Tiny Image Museum. The Status page of the site reads it.

| ID | Item | Status | Summary |
| --- | --- | --- | --- |
| T1 | The byte view | done | A GIF block parser in the page labels each byte of each real file. A press or a hover shows the label. |
| T2 | The live test | done | The page loads each file with `new Image()` in the browser of the visitor and shows the result and the natural size. |
| T3 | The shrink lab | done | The visitor changes the bytes of a tiny file. The page loads the result as an image after each change. |
| T4 | The side rooms | done | The rooms show the hidden text of `secret.gif`, the two readings of `runme.gif`, the reversed name, the terminal cell and the two empty frames. |
| T5 | The README against the bytes | done | The page compares each listed size with the real file and shows each difference. |
| T6 | A license | not started | The repository has no license. The owner decides. The conventions rule `license-file` stays off until then. |
| T7 | More formats in the byte view | not started | The parsers label GIF, SVG text and terminal codes. BMP and TGA stay without labels. |
